## 2. 当前实体关系

- `tblCourse`：选课模块的精简课程目录。
- `tblCourseSection`：实际教学班，引用课程、教师和开课院系。
- `tblSectionAudience`：教学班受众，支持全校或院系及入学年份范围。
- `tblCourseEnrollment`：选课记录，引用学生和教学班。
- `tblCatalogCourse`：成员 B 维护的东南大学公开培养方案快照，不直接作为教学班。

公开培养方案目录、选课课程目录与实际教学班职责不同，当前并存不会发生表名冲突。

## 3. 已验证规则

- 同一学生不能重复选择同一教学班，也不能选择同一课程的其他教学班。
- 选课前校验学籍状态、受众、时间窗口、容量和上课时间冲突。
- 同一教学班的容量竞争使用服务端锁保护，自动化并发测试未发生超额。
- 教师只能查询本人教学班及名单；名单不暴露电话和邮箱。
- 有选课记录的教学班不能删除。
- 有选课记录的学生、有教学班的教师、有教学班或目录数据的院系不能删除。
- 旧版选课表可由服务端识别并升级为 v2 演示结构。
