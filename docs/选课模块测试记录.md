## 3. 已验证场景

- 学生只看到在读、启用且满足受众规则的教学班；非目标院系或年份区间外的教学班不可见。
- 已选、未到选课窗口、窗口已结束、容量已满、时间冲突均返回明确原因且保持可见。
- 同一学生重复选同一教学班或同一门课的不同教学班被拒绝。
- 两名学生并发抢最后一个名额时，恰好一人成功，选课人数不超过容量（JVM 课程锁生效）。
- 教师只能查询本人教学班名单；管理员可查任意名单；名单不含电话、邮箱。
- 管理员可维护课程 / 教学班 / 受众 / 课程性质；删除仍有选课的教学班被拒绝。
- 课程性质与选课窗口格式校验生效。

## 4. 兼容性说明

- 检测到旧版选课表（选课记录引用课程编号而非教学班）时，服务端启动自动重建选课
  演示表并重写演示数据；不依赖手工迁移。
- 选课时间与选课时间窗口均采用受控文本，避免 UCanAccess 日期类型差异。
- 已知边界：课程锁为单服务器进程内的 JVM 锁；多进程部署时需改用数据库级原子更新。
