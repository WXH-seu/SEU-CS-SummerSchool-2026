## 3. 已验证业务场景

- 学生登录后课程目录只显示开放课程，课表返回本人选课记录。
- 重复选择同一门课程返回 `CONFLICT`。
- 课程容量已满时选课返回 `CONFLICT`。
- 与已选课程上课时间相同返回 `CONFLICT`。
- 学生可以退选自己的课程，退选不存在的记录返回 `NOT_FOUND`。
- 教师查询课程时服务端强制限定为本人课程，且不能选课或维护课程。
- 管理员可以新增、编辑和删除课程；删除仍有学生选课的课程返回 `CONFLICT`。
- 学生账号尝试维护课程返回 `FORBIDDEN`。
- 有选课记录的学生被外键保护，不能直接删除。

## 4. 兼容性处理记录

- 选课时间使用 `TEXT(19)` 保存 `yyyy-MM-dd HH:mm:ss`，沿用学籍模块避免
  Access/Jackcess 日期时间类型转换差异的策略。
- 课程学分使用 `DOUBLE`，容量使用 `INTEGER`；服务端对学分和容量做范围校验。
- 数据库表在服务端启动时自动补齐，不删除已有数据，兼容旧版本数据库升级。
