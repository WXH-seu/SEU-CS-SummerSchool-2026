## 3. 选课场景

实际课程从东南大学公开培养方案中选取代表性课程，覆盖计算机、软件、人工智能、网络
空间安全、信息通信和仪器方向。教学班包含全校受众和学院受众、多个教师、不同时间地点、
首修/重修容量、已满、时间冲突、尚未开始和停用等状态。

六个学生账号均至少能看到 8 个符合本人学院、年级的教学班。预置选课记录用于展示课程
容量和教师名单，历史修读记录用于展示首修与重修判定。

## 4. 初始化与兼容

账号按 `userId`、学籍按学号/工号、班级和教学班按固定编号逐项检查，只新增缺失数据。
现有账号的密码、资料和已有业务记录不会被覆盖。重复启动服务器不会产生重复数据。

初始化顺序为：账号 → 学籍基础表 → 东南大学公开目录 → 扩展班级/人员 → 课程/教学班 →
选课及修读记录。部署到既有服务器前仍应备份 `vCampus.accdb`。
