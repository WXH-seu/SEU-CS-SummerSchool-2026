## 3. 已验证异常场景

- 学生查询教师信息返回 `FORBIDDEN`。
- 学生查询学籍时只返回与本人账号关联的记录。
- 删除仍被班级或人员引用的院系返回 `CONFLICT`。
- 删除仍有学生的班级返回 `CONFLICT`。
- 学生所属班级与院系不一致时拒绝保存。
- 日期、年份、邮箱、学籍状态格式错误时拒绝保存。
- 关联账号不存在或角色不一致时拒绝保存。

## 4. 兼容性处理记录

测试发现 UCanAccess 5.0.1 在 Java 8 环境中处理部分 `DATETIME` 更新或删除时可能
出现 Jackcess 内部类型转换异常。学生出生日期因此使用 `TEXT(10)` 保存，服务端使用
`LocalDate` 严格验证格式和日期合法性。调整后真实 Access CRUD 和网络测试均通过。
