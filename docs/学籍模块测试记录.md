## 3. 已验证异常场景

- 学生查询教师信息返回 `FORBIDDEN`。
- 学生查询学籍时只返回与本人账号关联的记录。
- 删除仍被班级或人员引用的院系返回 `CONFLICT`。
- 删除仍有学生的班级返回 `CONFLICT`。
- 删除仍有借阅、预约、推荐、购物车或订单记录的学生、教师返回 `CONFLICT`。
- 学生所属班级与院系不一致时拒绝保存。
- 日期、年份、邮箱、学籍状态格式错误时拒绝保存。
- 关联账号不存在或角色不一致时拒绝保存。

## 4. 兼容性处理记录

测试发现 UCanAccess 5.0.1 在 Java 8 环境中处理部分 `DATETIME` 更新或删除时可能
出现 Jackcess 内部类型转换异常。学生出生日期因此使用 `TEXT(10)` 保存，服务端使用
`LocalDate` 严格验证格式和日期合法性。调整后真实 Access CRUD 和网络测试均通过。

旧选课结构升级必须先删除引用教学班的 `tblCourseEnrollment`、`tblSectionAudience` 和
`tblSectionSchedule`，再删除教学班与课程主表。本轮增加部分升级结构回归用例，避免
Jackcess 在主表先删时留下悬挂关系。已经损坏、元数据中引用不存在表的历史文件不自动
覆盖，应先备份并使用全新数据库初始化。
