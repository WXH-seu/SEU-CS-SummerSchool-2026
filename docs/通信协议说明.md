# vCampus 通信协议说明

## 1. 设计目标

五个业务模块共用一套对象流协议，客户端和服务端只依赖 `vcampus-common` 中的共享类，
避免两端消息定义不一致。协议层不包含 Swing、数据库或具体业务实现。

## 2. 消息结构

### 请求 `RequestMessage<T>`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| requestId | String | 每次请求的唯一编号，用于响应匹配 |
| operation | Operation | 业务操作类型 |
| sessionToken | String | 登录后获得的会话令牌，未登录可为空 |
| body | T | 可序列化请求体，可为空 |

### 响应 `ResponseMessage<T>`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| requestId | String | 与请求一致，客户端据此校验 |
| code | ResponseCode | 结果状态 |
| message | String | 人类可读说明 |
| body | T | 可序列化响应体 |

### 状态码 `ResponseCode`

`SUCCESS`、`INVALID_REQUEST`、`UNAUTHORIZED`、`FORBIDDEN`、`NOT_FOUND`、
`CONFLICT`、`NOT_IMPLEMENTED`、`SERVER_ERROR`。

## 3. Socket 生命周期

```text
客户端连接 -> 登录(USER_LOGIN) -> 携带 sessionToken 发起业务请求
          -> 登出(USER_LOGOUT) -> 关闭连接
```

- 客户端默认连接 `127.0.0.1:4444`，可通过外部配置修改。
- 连接建立后先发送 `ObjectOutputStream` 头，再循环读写对象流。
- 每个请求同步等待响应，客户端按 `requestId` 校验匹配。
- 网络断开、超时或消息格式错误时，客户端抛出 `IOException`，由页面统一提示。

## 4. 请求分发

```text
ClientHandler（每个连接一个线程）
  -> RequestDispatcher（按 Operation 分发）
  -> 模块 Handler（AcademicRequestHandler / CourseRequestHandler / LibraryRequestHandler / StoreRequestHandler）
  -> Service -> DAO
```

新增业务模块的接入步骤：

1. 在 `Operation` 中增加操作类型。
2. 在 `vcampus-common` 增加可序列化 DTO。
3. 在服务端增加模块 `RequestHandler`，在 `RequestDispatcher` 注册。
4. 在客户端增加 `ClientService`，通过 `ClientConnection.request` 发送。
5. 更新协议文档并通知全组同步打包。

## 5. 容错规则

- 未知操作返回 `NOT_IMPLEMENTED`，不影响服务器继续运行。
- 无效消息类型或无法反序列化的消息返回 `INVALID_REQUEST`。
- 未登录请求返回 `UNAUTHORIZED`，权限不足返回 `FORBIDDEN`。
- 数据库约束冲突转换为 `CONFLICT`，其他数据库异常返回 `SERVER_ERROR`。
- 单个客户端异常退出只关闭自己的连接，不会导致服务器整体退出。
- 日志中不输出密码、完整会话令牌或敏感个人信息。

## 6. 序列化要求

- 所有传输对象实现 `Serializable` 并声明 `serialVersionUID`。
- DTO 只使用 `vcampus-common` 中定义的类型，不使用 `ArrayList` 等具体容器作为字段类型。
- 客户端和服务端必须使用同一版本的 `vcampus-common`，任何公共类变更需同时重新打包。

## 7. 最小通信示例

```java
ResponseMessage<?> login = connection.request(new RequestMessage<LoginRequest>(
        Operation.USER_LOGIN, null, new LoginRequest("student", "student123")));
LoginResponse session = (LoginResponse) login.getBody();

CourseClientService courses =
        new CourseClientService(connection, session.getSessionToken());
List<CourseDto> catalog = courses.queryCourses(null);
```
