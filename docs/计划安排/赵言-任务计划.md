# 赵言 任务计划

## 1. 岗位定位

- 角色：图书馆模块负责人、Swing 界面规范负责人。
- 目标：完成图书馆完整业务，并统一客户端页面结构、交互和视觉规范。
- 工作边界：负责公共界面规范和可复用组件，各模块负责人完成本模块页面内容。

## 2. 业务任务

- 实现图书检索、详情查看、借阅和归还。
- 实现个人借阅记录和借阅状态查询。
- 实现图书库存、可借数量和必要的逾期状态管理。
- 实现管理员对图书资料和库存的维护。
- 实现图书馆 Swing 页面、服务端业务和 DAO。
- 准备图书馆演示数据和异常测试场景。

## 3. 四周计划

| 周次 | 任务 | 交付物 |
| --- | --- | --- |
| 第一周 | 完成主要界面原型、导航结构、图书馆业务流程和数据需求 | 界面原型、交互规范、图书馆模块设计 |
| 第二周 | 建立公共 Swing 组件和页面模板；实现图书查询与基础管理 | 公共界面组件、图书查询和维护功能 |
| 第三周 | 完成借阅、归还、记录和库存处理；统一各模块界面 | 图书馆完整业务链路、界面集成版本 |
| 第四周 | 进行易用性和异常提示检查；编写系统使用说明 | 使用说明、界面检查记录、演示页面 |

## 4. 公共职责

- 统一窗口尺寸、导航、按钮、表格、表单和提示框的使用方式。
- 提供可复用的页面基类或公共 Swing 组件。
- 检查界面是否在机房常见分辨率下正常显示。
- 汇总各模块操作步骤，编写系统使用说明。
- 协助准备答辩演示界面和截图。

## 5. 协作接口

- 与成员 B 确认图书、库存和借阅记录的表结构。
- 与成员 C 接入图书馆相关请求和响应。
- 与成员 A 确认学生和管理员的操作权限。
- 向其他成员提供界面规范，并帮助其处理公共组件问题。
- 接受成员 C 的代码审核，并审核成员 E 的代码与文档。

## 6. 完成标准

- [ ] 用户能够检索图书并查看库存状态。
- [ ] 借阅和归还能够正确更新库存与个人记录。
- [ ] 库存不足、重复借阅等异常能够被正确处理。
- [ ] 管理员能够维护图书资料和库存。
- [ ] 客户端页面布局统一，提示清晰，无明显遮挡或错位。
- [ ] 系统使用说明覆盖五个必做模块的主要操作。
- [ ] 图书馆模块和公共界面代码具备 JavaDoc 与测试记录。
