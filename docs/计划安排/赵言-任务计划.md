# 赵言 任务计划

## 1. 岗位定位

- 角色：图书馆模块负责人、Swing 界面规范负责人。
- 目标：完成图书馆完整业务，并统一客户端页面结构、交互和视觉规范。
- 工作边界：负责公共界面规范和可复用组件，各模块负责人完成本模块页面内容。

## 2. 业务任务

- 实现图书检索、详情查看、借阅和归还。
- 实现个人借阅记录和借阅状态查询。
- 实现图书库存、可借数量和逾期状态管理。
- 实现管理员对图书资料和库存的维护。
- 实现续借：首次借期 30 天，当前借期内最后 10 天可续借 30 天，同一借阅最多续借 2 次。
- 实现逾期限制：有书逾期则禁止再借和续借。
- 实现预约委托：馆藏不足时可向管理员申请；被预约副本不可续借，到期必须归还；管理员锁定保管一周供申请人取书；超一周未取记违约一次，满 3 次停权 30 天。
- 实现好书推荐：师生提交书名与作者许愿；管理员审核批准或拒绝引进。
- 实现图书馆 Swing 页面、服务端业务和 DAO。
- 准备图书馆演示数据和异常测试场景。

详细规则见 [图书馆模块说明](../图书馆模块说明.md)。

## 4. 公共职责

- 统一窗口尺寸、导航、按钮、表格、表单和提示框的使用方式。
- 提供可复用的页面基类或公共 Swing 组件。
- 检查界面是否在机房常见分辨率下正常显示。
- 汇总各模块操作步骤，编写系统使用说明。
- 协助准备答辩演示界面和截图。



## 5. 协作接口

- 与成员 B 确认图书、副本、借阅、预约委托、好书推荐和续借相关表结构。
- 与成员 C 接入图书馆请求和响应，含续借、预约、推荐等操作。
- 与成员 A 确认学生、教师和管理员在本模块的操作权限。
- 向其他成员提供界面规范，并帮助其处理公共组件问题。
- 接受成员 C 的代码审核，并审核成员 E 的代码与文档。

- [x] 库存不足、重复借阅等异常能够被正确处理。
- [x] 管理员能够维护图书资料和库存。
- [x] 师生可在当前借期最后 10 天续借，同一借阅最多 2 次；被预约副本不可续借。
