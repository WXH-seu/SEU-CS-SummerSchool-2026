## 第二周：核心功能（已完成）

- [x] 协议层：新增 `USER_REGISTER`、`USER_ACCOUNT_QUERY`、`USER_PROFILE_UPDATE`、
  `USER_PASSWORD_CHANGE`、`USER_DELETE`、`USER_LIST_QUERY`、`USER_STATUS_UPDATE`，
  以及 7 个请求/响应 DTO；`ResponseCode` 新增 `CONFLICT`。
- [x] 服务端：`AuthService` 实现注册（自动登录）、登录、登出、注销（密码确认）、
  修改显示名、修改密码、账号查询、用户列表与启用/禁用；`AuthException` 统一业务错误。
- [x] 权限模块：`PermissionPolicy` 统一权限矩阵，dispatcher 按
  “公开 → 会话校验 → 角色校验 → 分发”顺序处理所有请求。
- [x] 数据访问：`UserRepository` 扩展 6 个方法，`AccessUserRepository` 实现；
  密码 PBKDF2 加盐哈希，不落明文。
- [x] 客户端：`LoginFrame`（登录 + 注册入口 + 演示账号提示）、`RegisterFrame`（注册）、
  `MainFrame`（账号管理 / 退出登录入口 + 角色权限提示）、`AccountFrame`（账号管理 +
  管理员用户管理）、`UserClientService` 服务封装。
