# 林道军 任务计划

## 1. 岗位定位

- 角色：校园商店模块负责人、测试与部署负责人。
- 目标：完成校园商店完整业务，并保证项目可以在 JDK 1.8、Eclipse 和 Access 环境中稳定构建与运行。
- 工作边界：负责总体测试和部署流程，各模块负责人仍需完成本模块测试。

## 2. 业务任务

- 实现商品浏览、搜索和详情查看。
- 实现购物车添加、修改数量和移除商品。
- 实现订单创建、订单查询和基础状态管理。
- 实现商品库存检查和下单扣减。
- 实现管理员对商品和库存的维护。
- 实现商店 Swing 页面、服务端业务和 DAO。

## 3. 四周计划

| 周次 | 任务 | 交付物 |
| --- | --- | --- |
| 第一周 | 制定测试策略；验证 Eclipse、JDK 1.8、Maven 和 Access 基础环境；完成商店设计 | 测试计划、兼容性记录、商店模块设计 |
| 第二周 | 建立测试记录模板和构建配置；实现商品查询与基础管理 | 测试模板、构建配置、商品管理功能 |
| 第三周 | 完成购物车、订单和库存处理；开始模块集成测试 | 商店完整业务链路、第一轮测试报告 |
| 第四周 | 组织功能、权限、并发、异常和部署测试；完成 JAR 打包 | 测试报告、部署说明、客户端和服务器端 JAR |

## 4. 公共职责

- 建立功能、权限、网络、数据库和异常测试清单。
- 组织各模块交叉测试并跟踪问题关闭情况。
- 检查所有代码和构建产物是否兼容 JDK 1.8。
- 验证项目可在 Eclipse 中导入、编译和启动。
- 负责生成 `vCampusClient.jar`、`vCampusServer.jar` 和 JavaDoc。
- 编写部署说明，并在干净环境中进行最终演练。

## 5. 协作接口

- 与成员 B 确认商品、购物车、订单和库存表结构。
- 与成员 C 接入商店相关请求和响应。
- 与成员 A 确认用户和管理员权限，并测试最终集成版本。
- 与成员 D 统一商店界面和操作说明。
- 接受成员 D 的代码审核，并审核成员 A 的代码与文档。

## 6. 完成标准

- [ ] 用户能够浏览商品、管理购物车、创建并查询订单。
- [ ] 下单时库存校验和扣减结果正确。
- [ ] 管理员能够维护商品和库存。
- [ ] 测试清单覆盖五个必做模块和关键异常流程。
- [ ] 项目在 JDK 1.8 和 Eclipse 环境下通过构建与运行验证。
- [ ] Access 数据库无需配置 DNS/ODBC 数据源即可连接。
- [ ] 两个可执行 JAR、JavaDoc 和部署说明可以用于最终提交。
