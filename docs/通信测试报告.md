# vCampus 通信测试报告

## 1. 范围与环境

| 项目 | 内容 |
| --- | --- |
| 测试对象 | Socket 通信框架、请求分发、会话与异常容错 |
| 日期 | 2026-09-10 |
| Java | Java SE 1.8 |
| 构建 | Maven 3.9.x |
| 数据库 | 临时 Access 数据库（测试自动创建） |

## 2. 测试用例与结果

### 2.1 服务端容错（`NetworkFaultToleranceTest`，进程内启动真实服务器）

| 用例 | 验证内容 | 结果 |
| --- | --- | --- |
| `pingOverSocketSucceeds` | 对象流连接、请求响应往返 | 通过 |
| `invalidMessageIsRejectedWithoutStoppingServer` | 非法对象返回 `INVALID_REQUEST`，随后新连接可正常通信 | 通过 |
| `protectedOperationWithoutSessionIsUnauthorized` | 未登录访问受保护操作返回 `UNAUTHORIZED` | 通过 |
| `loginThenProtectedOperationPassesSessionCheck` | 登录后携带 token 可越过会话校验（示例分发器未挂业务处理器，因此返回 `NOT_IMPLEMENTED`） | 通过 |
| `abruptDisconnectDoesNotStopOtherClients` | 客户端异常断开后服务器继续服务其他连接 | 通过 |
| `parallelClientsAreServedConcurrently` | 三个客户端并发请求均得到响应（线程池） | 通过 |

### 2.2 客户端容错（`ClientConnectionFaultTest`，桩服务器）

| 用例 | 验证内容 | 结果 |
| --- | --- | --- |
| `unreachableServerFailsFast` | 服务器未启动时连接快速失败并抛出 `IOException` | 通过 |
| `unexpectedResponseObjectIsRejected` | 服务器返回非 `ResponseMessage` 对象时客户端拒绝并提示 | 通过 |
| `silentServerTriggersReadTimeout` | 服务器保持连接但不响应时，按 15 秒读超时抛出异常 | 通过（实测 ≥14 秒） |

### 2.3 性能与并发相关

| 用例 | 验证内容 | 结果 |
| --- | --- | --- |
| `CourseServiceIntegrationTest.concurrentSelectionNeverOversells` | 两个客户端并发抢最后一个名额，仅一人成功 | 通过 |
| `NetworkAcademicSmokeTest` / `NetworkCourseSmokeTest` / `NetworkLibrarySmokeTest` | 真实服务器上的登录、学籍、选课、图书馆链路 | 通过（需 `-Dvcampus.network.test=true`） |

## 3. 通信参数

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 默认端口 | 4444 | `ProtocolConstants.DEFAULT_PORT` |
| 连接超时 | 5 秒 | 连不上立即报错 |
| 读超时 | 15 秒 | 已连接但服务器无响应时触发 |
| 线程池 | 16（默认） | 支持多客户端并发；单连接内请求串行处理 |

## 4. 结论与已知限制

- 非法消息、未登录访问、客户端异常断开均不会导致服务器退出，容错符合完成标准。
- 客户端对“连不上 / 返回异常对象 / 服务器沉默”三种故障都能给出明确错误，不会无限阻塞。
- 选课并发超卖由“按课程粒度的 JVM 锁 + 数据库唯一约束”共同防护，已验证最后名额场景。
- 已知限制：课程锁是单服务器进程内的锁；若将来多进程部署，需要改为数据库级原子更新。
- 未启用邮件配置时，服务器启动会提示 `mail service disabled`，不影响选课与通信功能。

## 5. 复现方式

```bash
# 单元与集成测试（含服务端容错）
mvn test

# 客户端容错（含 15 秒读超时用例）
mvn -pl vcampus-client -am test -Dtest=ClientConnectionFaultTest

# 真实服务器冒烟：先启动 vCampusServer，再执行
mvn -pl vcampus-client -am test -Dvcampus.network.test=true
```
