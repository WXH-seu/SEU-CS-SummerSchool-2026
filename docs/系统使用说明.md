# vCampus 系统使用说明

本说明覆盖五个必做模块的日常操作。详细规则见各模块设计文档；界面约定见《Swing 界面组件说明》。

## 1. 启动

必须从仓库根目录启动，以便默认数据库路径正确。

1. 先启动服务端：`java -jar vcampus-server/target/vCampusServer.jar`
2. 再启动客户端：`java -jar vcampus-client/target/vCampusClient.jar`
3. 客户端默认连接 `127.0.0.1:4444`。

首次启动会自动创建 `vcampus-database/vCampus.accdb` 并写入演示数据。

### 演示账号

| 角色 | 账号 | 密码 | 用途 |
| --- | --- | --- | --- |
| 超级管理员 | `superadmin` | `super123` | 注册用户、导入 CSV、启用/禁用账号、查看操作日志 |
| 子系统管理员 | `admin` | `admin123` | 管理全部业务子系统 |
| 教师 | `teacher` | `teacher123` | 借还、推荐、预约；查看教学班名单 |
| 学生 | `student` | `student123` | 选课、借还、购物；只能看本人学籍 |

账号由管理员创建，登录页没有自助注册。忘记密码时，若账号已登记邮箱，可在登录页按提示重置。

登录后顶栏可进入：应用中心、学籍管理、选课系统、图书馆、校园商店、账号管理。

## 2. 用户与账号

使用 `superadmin` 登录，打开「账号管理」。

1. 注册单个教师或管理员：填写账号、显示名、角色；子系统管理员须勾选可管理的子系统。
2. 批量导入学生：使用 `docs/学生学籍批量导入模板.csv`。
3. 可修改本人显示名和密码；超级管理员可启用、禁用账号并查看操作日志。
4. 子系统管理员不能注册用户或管理账号，只操作被授权的业务模块。

## 3. 学籍管理

使用 `admin` 打开「学籍管理」，可切换学生、教师、院系、班级、专业目录和培养方案课程。

1. 按学院、班级或关键字查询；学院和班级用下拉选择，不要手填编号。
2. 新增院系和班级时设置班级容量（默认 50）。新增学生时班级可留空，系统按学院、入学年份和容量自动分班。
3. 可用 CSV 批量导入新生，界面会给出成功数、失败数和分班结果。
4. 删除前请先处理关联数据：有学生的班级、仍被引用的院系、有选课或图书馆记录的学生/教师都不能删，应先停用或处理业务记录。
5. 使用 `student` 登录只能看到并修改本人的性别、出生日期、电话和邮箱。教师可查询学籍，不能改。

培养方案课程查询需指定专业代码，例如 `080901`（计算机科学与技术）。目录只读。

## 4. 选课系统

使用 `student` 打开「选课系统」。

1. 目录中可见满足受众规则的教学班。已选、未到窗口、窗口已结束、容量已满或时间冲突的课程仍显示，但按钮置灰并给出原因。
2. 选课后在「我的课表」查看；可退课。重复选择同一门课的不同教学班会被拒绝。
3. 使用 `teacher` 登录只能看到本人教学班，并可查看选课名单（不含电话、邮箱）。
4. 使用 `admin` 登录可新增、编辑、删除教学班，配置受众、选课窗口和课程性质。仍有学生选课的教学班不能删除。

## 5. 图书馆

使用 `student` 打开「图书馆」。页签为：书目、我的借阅、好书推荐、我的预约。管理员对应为全部借阅、预约委托。

### 5.1 借还与续借

1. 书目默认列出 10 种演示图书及可借数量。可按书名、ISBN 或作者查询。
2. 演示学生有《高等数学（上册）》在借和《红楼梦》逾期。有逾期时不能再借、不能续借，须先还逾期书。
3. 归还《红楼梦》后，可借《线性代数》；同一书不能重复借。
4. 《高等数学（上册）》处于续借窗口时，在「我的借阅」续借，应还日延后 30 天，最多续 2 次。刚借出的书未到窗口不可续。
5. 使用 `teacher` 同样可以借还。使用 `admin` 没有借阅按钮，可在「全部借阅」查看借阅人，并可新增、编辑、下架书目。有借阅记录的书不能删除，应先下架。

### 5.2 预约委托

适用：目标书在架但可借为 0。演示可用《围城》（1 册）。

1. 教师先借走《围城》，学生在书目页点「预约」。
2. 管理员在「预约委托」批准或拒绝。批准后该册不能续借。
3. 教师归还后，该册锁定 7 天。学生或管理员办理取书，借阅记在申请人名下。申请人若仍有逾期或已在借该书，须先处理再取。
4. 超过 7 天未取，副本回到可借，申请人记违约 1 次；累计 3 次后停权 30 天。

### 5.3 好书推荐

1. 师生在「好书推荐」提交书名和作者。教师演示账号有一条待审《三体》，学生有一条已拒绝《百年孤独》。
2. 管理员批准时补全 ISBN、馆藏等后写入书目；拒绝只改推荐状态。
3. 管理员不能提交推荐。

## 6. 校园商店

使用 `student` 或 `teacher` 打开「校园商店」。页签为：商品、购物车、我的订单。管理员没有购物车，可维护商品并处理全部订单。

1. 浏览上架商品，可按名称或分类筛选。`P005` 运动水壶库存为 0，用于演示缺货；已下架商品仅管理员可见。
2. 加入购物车后可改数量（数量为 0 即移除），可勾选多行批量移除或结算。
3. 结算前可查看校园钱包余额并充值。余额不足时下单失败，购物车和库存不变。
4. 确认支付后生成已付款订单，并扣减余额与库存。取消支付不发请求。
5. 管理员可改订单状态：待付款 / 已付款 / 已发货 / 已完成 / 已取消。被购物车或订单引用的商品不能删除，应先下架。

## 7. 常见提示

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 权限不足 / `FORBIDDEN` | 当前角色不能做该操作 | 换有权限的账号，或联系管理员授权子系统 |
| 未登录 / `UNAUTHORIZED` | 会话无效或已过期 | 重新登录 |
| 冲突 / `CONFLICT` | 库存不足、重复借阅、仍有关联数据等 | 按提示先还书、退课、下架或处理关联记录 |
| 操作失败且提到网络 | 服务端未启动或连接中断 | 确认服务端正在运行后再试 |

客户端请求都在后台执行，操作过程中请等待状态栏提示完成，不要重复连点。
