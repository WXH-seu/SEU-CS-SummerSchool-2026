# 东南大学公开数据快照

## 1. 用途与边界

本快照为虚拟校园课程项目提供接近真实学校结构的演示数据，包含公开的院系、专业、
课程及专业课程关系。它不包含学生、教师、联系方式、成绩等个人数据，也不访问需要登录、
验证码或校园网权限的系统。

服务器运行时只读取 JAR 内的 CSV 文件，不实时访问互联网。这样可以在机房断网、官网改版
或响应较慢时稳定演示，也避免把网络采集失败传播到业务功能。

数据表保存了每条记录的 `sourceYear` 与 `sourceUrl`，不得把不同年份误称为同一届完整课表。

## 4. 文件与更新方法

快照文件位于：

```text
vcampus-server/src/main/resources/seed/seu/
  sources.csv
  departments.csv
  majors.csv
  courses.csv
  major_courses.csv
```

联网重新采集并验证官方来源：

```bash
python tools/seu_catalog/build_snapshot.py --snapshot-date YYYY-MM-DD
```

仅根据上一次人工审核内容重新生成，不联网：

```bash
python tools/seu_catalog/build_snapshot.py --offline --snapshot-date YYYY-MM-DD
```

培养方案 PDF 使用了不能可靠文本提取的中文自定义字体，因此脚本不会把乱码自动写进数据。
课程常量由项目成员在渲染 PDF 页面后人工复核。更新时必须检查 CSV 差异、课程代码、学分、
学年学期及来源年份，再运行测试并提交。

## 5. 数据库导入

`AccessCurriculumCatalogRepository` 在服务端启动时完成以下工作：

1. 为旧版 `tblDepartment` 补充官网、来源和采集日期字段。
2. 创建 `tblCatalogSource`、`tblMajor`、`tblCourse` 和 `tblMajorCourse`。
3. 按稳定主键更新或插入快照数据，并在一个事务内提交。
4. 通过外键保证院系、来源、专业和课程关系完整。

导入是幂等的；重复启动不会产生重复记录，也不会删除使用者另行录入的数据。
