# 图书馆模块说明

## 1. 功能范围

模块覆盖图书检索、库存查看、借阅、归还、续借、逾期限制、预约委托、好书推荐、个人借阅记录，以及管理员对书目、馆藏、预约和推荐的维护。
模块包含公共 DTO、协议操作、服务端权限校验、Access DAO、Swing 页面和自动化测试。

当前已实现：检索、库存、借阅、归还、续借、逾期禁借/禁续、个人/全部借阅记录、管理员书目维护、好书推荐、预约委托。

## 2. 角色权限


| 角色  | 图书检索     | 借阅 / 归还 / 续借 | 借阅记录       | 预约委托           | 好书推荐  | 资料维护          |
| --- | -------- | ------------ | ---------- | -------------- | ----- | ------------- |
| 管理员 | 允许（含已下架） | 禁止           | 全部在借（含借阅人） | 审核申请、锁定保管、办理取书 | 审核引进  | 允许新增、编辑、下架和删除 |
| 教师  | 允许（仅在架）  | 允许（限本人）      | 仅本人（含已还）   | 可申请、可取书        | 可提交许愿 | 禁止            |
| 学生  | 允许（仅在架）  | 允许（限本人）      | 仅本人（含已还）   | 可申请、可取书        | 可提交许愿 | 禁止            |


权限在服务端 `LibraryService` 中执行。未登录请求由 `RequestDispatcher` 拒绝。
客户端隐藏无权操作的按钮只是交互优化，不能代替服务端鉴权。

超级管理员以及被授予图书馆作用域的子系统管理员，在本模块的有效角色都是管理员，因此只能维护书目、审核预约和推荐，不能借还或续借。未授予图书馆作用域的子系统管理员归一化为教师，仍可借还、续借、预约和推荐，不能维护书目。

## 3. 调用链

```text
LibraryPanel（书目 / 我的借阅或全部借阅 / 好书推荐 / 预约委托或我的预约）
  -> LibraryClientService
  -> RequestMessage / ClientConnection
  -> RequestDispatcher
  -> LibraryRequestHandler
  -> LibraryService
  -> AccessBookRepository
  -> vCampus.accdb
```

客户端查询、借阅、归还及后续写操作均通过 `SwingWorker` 执行，不阻塞 Swing 事件线程。

## 4. 协议操作


| 操作                       | 请求体                                            | 响应体                          | 状态  |
| ------------------------ | ---------------------------------------------- | ---------------------------- | --- |
| `LIBRARY_BOOK_QUERY`     | `BookQueryRequest`                             | `ArrayList<BookSummary>`     | 已实现 |
| `LIBRARY_BOOK_SAVE`      | `BookDto`                                      | 保存后的 `BookDto`               | 已实现 |
| `LIBRARY_BOOK_DELETE`    | `EntityIdRequest`（ISBN）                        | `OK`                         | 已实现 |
| `LIBRARY_BORROW`         | `BorrowRequest`（ISBN）                          | `BorrowRecordDto`            | 已实现 |
| `LIBRARY_RETURN`         | `ReturnRequest`（recordId）                      | `OK`                         | 已实现 |
| `LIBRARY_RENEW`          | `ReturnRequest`（recordId）                      | `BorrowRecordDto`            | 已实现 |
| `LIBRARY_BORROW_QUERY`   | 空                                              | `ArrayList<BorrowRecordDto>` | 已实现 |
| `LIBRARY_WISH_QUERY`     | 空                                              | `ArrayList<WishDto>`         | 已实现 |
| `LIBRARY_WISH_SUBMIT`    | `WishSubmitRequest`（书名 + 作者）                   | `WishDto`                    | 已实现 |
| `LIBRARY_WISH_REVIEW`    | `WishReviewRequest`（编号 + 批准/拒绝，批准时带 `BookDto`） | `OK` 或写入后的 `BookDto`         | 已实现 |
| `LIBRARY_RESERVE_QUERY`  | 空                                              | `ArrayList<ReserveDto>`      | 已实现 |
| `LIBRARY_RESERVE_APPLY`  | `BorrowRequest`（ISBN）                          | `ReserveDto`                 | 已实现 |
| `LIBRARY_RESERVE_REVIEW` | `ReserveReviewRequest`（编号 + 批准/拒绝）             | `OK`                         | 已实现 |
| `LIBRARY_RESERVE_PICKUP` | `ReserveIdRequest`（申请编号）                       | `BorrowRecordDto`            | 已实现 |


关键字为空或请求体为空时，返回全部在架书目。管理员可将 `includeInactive` 设为 true
以包含已下架书目；学生和教师即使传入该标记也会被服务端忽略。
`BookSummary` 包含可借册数、馆藏册数和在架状态。保存操作同时支持新增和修改，
ISBN 在首次保存后不可通过客户端编辑。
`LIBRARY_BORROW_QUERY` 对学生和教师返回本人全部借阅（含已还）；对管理员返回当前
未还记录，`BorrowRecordDto` 带 `userId` 与 `displayName`。
`LIBRARY_WISH_QUERY` 对学生和教师返回本人推荐；对管理员返回全部推荐，待审排在前面。
`LIBRARY_RESERVE_QUERY` 对学生和教师返回本人预约；对管理员返回全部预约，进行中的排在前面。

## 5. 主要业务规则



### 5.1 书目与借还（已实现）

- 仅返回 `active = true` 的书目，除非管理员明确查询已下架记录。
- 可按 ISBN、书名或作者模糊匹配。
- 可借数量统计状态为 `AVAILABLE` 的副本。
- 馆藏册数必须在 1 到 100 之间，且不能少于当前在借数量。
- 减少馆藏时只删除从未产生借阅记录的可借副本。
- 仍有在借副本或历史借阅记录的图书不能删除，应先下架（`active = false`）。
- 借阅人使用登录账号 `userId`；仅学生和教师可以借还，管理员只维护书目并查看全部在借。
- 首次借期 30 天。同一人同一 ISBN 存在未还记录时拒绝重复借阅。
- 已下架或无可借副本时拒绝借阅。
- 只能归还本人的未还记录；逾期仍可归还，界面标记为「逾期」。管理员不能代还。
- 借还必须在同一短事务中更新副本状态和借阅记录。
- 演示数据中《高等数学（上册）》有 1 册在借，《红楼梦》有 1 册逾期未还。

需要展示学号、班级等资料时，通过学籍表的 `userId` 关联查询。

### 5.2 续借（已实现）

- 首次借期 30 天，与现有借阅一致。
- 可续借窗口：当前应还日前 10 天内（含应还日当天），且尚未逾期。
- 每次续借从原应还日起再延长 30 天。第一次续借后，新的 30 天期末 10 天内仍可再续，直到满 2 次。
- 同一条借阅记录最多续借 2 次。
- 拒绝续借：已逾期、已归还、不在窗口内、已达 2 次、该副本已被生效的预约委托命中、操作者不是借阅人、管理员账号。
- 生效预约指状态为已批准（`APPROVED`）且已命中该副本的申请；锁定保管中的副本已不在借，续借拦截不再适用。
- 界面在「我的借阅」提供续借按钮；服务端再次校验全部条件。
- 新库演示数据中《高等数学（上册）》处于可续借窗口（约剩余 5 天）；账号上若还有《红楼梦》逾期，须先归还才能续借其他书。



### 5.3 逾期限制（已实现）

- 账号下任意在借记录逾期时，禁止再借任何图书，也禁止续借；归还、预约申请不受影响。
- 全部逾期图书归还后，借阅限制解除。
- 不从校园卡扣逾期费用，也不改商店余额规则。



### 5.4 预约委托（已实现）

适用：目标书目在架，但可借册数为 0（副本均在借或锁定）。学生或教师可向管理员提交预约委托申请。管理员不能申请。演示库不预置预约记录，可用《围城》（1 册）走完流程。


| 步骤  | 规则                                                              |
| --- | --------------------------------------------------------------- |
| 申请  | 同一用户对同一 ISBN 只能有一条进行中的申请。已在借该书、仍有可借副本、已下架或停权期内不能申请。逾期未还不阻止申请。   |
| 审核  | 管理员批准或拒绝。批准后命中应还日最早、且尚未被其他已批准预约占用的一册在借副本，该册禁止续借。                |
| 到期  | 被命中副本必须在原借期届满时归还，不可续借。                                          |
| 保管  | 归还后该副本进入 `HELD`，保管 7 天，可借数不计该册。                                 |
| 取书  | 7 天内申请人可取书，生成新的 30 天借阅。管理员可办理取书，但借阅记在申请人名下。申请人有逾期未还或已在借该书时不能取。  |
| 违约  | 保管截止时刻已过仍未取：副本回到 `AVAILABLE`，申请人记违约 1 次。查询、借还、续借和预约操作都会先结算超期保管。 |
| 停权  | 累计违约满 3 次，自第三次违约起停权 30 天，期间不能提交新预约。停权期满后恢复资格，违约次数清零。            |


副本状态为 `AVAILABLE`、`BORROWED`、`HELD`。
进行中的预约包括：待审（`PENDING`）、待归还（`APPROVED`）、待取书（`HELD`）。
界面：书目页「预约」；师生「我的预约」可取书；管理员「预约委托」可批准、拒绝和办理取书。

### 5.5 好书推荐（已实现）

图书馆增加「好书推荐」页签。

- 学生和教师提交许愿，必填书名和作者；同一人相同书名和作者只能有一条待审推荐。
- 管理员查看全部推荐，批准或拒绝引进；师生只看本人提交记录及审核结果。
- 批准时弹出新增书目表单（书名、作者已填），管理员补全 ISBN、馆藏册数等后写入书目；写入失败则推荐仍为待审。
- 拒绝只更新该条推荐状态，不改书目。
- 管理员不能提交推荐。演示库预置教师待审《三体》和学生已拒绝《百年孤独》。



## 6. 演示流程



### 6.1 借还与维护（已实现）

1. 启动服务端和客户端，使用 `student/student123` 登录。
2. 打开“图书馆”，确认默认列出 10 种演示图书及可借数量，且没有新增/编辑/删除按钮。
3. 打开“我的借阅”，确认有《高等数学（上册）》在借和《红楼梦》逾期各一条。
4. 归还《红楼梦》，确认状态变为已还，书目中可借数加 1。
5. 在书目中借阅《线性代数》，确认可借数减 1，并出现在“我的借阅”。
6. 再次借阅《线性代数》，确认服务器拒绝重复借阅。
7. 使用 `teacher/teacher123` 登录，确认教师也能借还。
8. 使用 `admin/admin123` 登录，确认没有借阅按钮；打开「全部借阅」，确认能看到演示学生的在借和逾期记录及借阅人；新增一种图书，修改馆藏册数，再将其下架。
9. 尝试删除《红楼梦》，确认服务器因存在借阅记录而拒绝，提示改用下架。



### 6.2 续借、逾期、预约与推荐

1. （已实现）学生打开「我的借阅」，《红楼梦》逾期。此时借《线性代数》或续借《高等数学（上册）》均被拒绝。归还《红楼梦》后可再借；新库中《高等数学（上册）》处于应还日前 10 天内，续借成功后应还日延后 30 天、续借次数变为 1/2。刚借出的书未到窗口不可续。不扣校园卡。
2. （已实现）教师借走《围城》后可借为 0，学生提交预约；管理员批准后教师无法续借。归还后该册锁定 7 天，学生或管理员办理取书，借阅记在学生名下。学生若仍有逾期未还，须先归还才能取书。
3. （已实现）锁定超过 7 天未取，副本回到可借、申请人违约次数加 1；累计 3 次后 30 天内不能再预约，期满后违约清零并可再申请。
4. （已实现）师生在「好书推荐」提交书名和作者；管理员批准并补全 ISBN 后书目出现该种；拒绝后书目不变。教师演示账号有一条待审《三体》，学生有一条已拒绝《百年孤独》。



## 7. 扩展注意事项

- 公共 DTO 或 `Operation` 变更后，客户端和服务端必须同时重新打包。
- 续借、预约、推荐相关表结构变更须同步更新《数据库设计说明》和《数据库变更记录》，并通知成员 B。
- 学籍删除学生或教师时会检查该账号的借阅、预约和推荐记录；有记录时返回 `CONFLICT`，应先在图书馆处理后再删学籍。
